# 구현 연결표 (디자인 고도화 2탄)

우선순위 = 영향 × 빈도 × 확신 ÷ 비용 (각 1~5). 접근성 결함은 점수와 상관없이 먼저.

| 순위 | 문제 (진단) | 레퍼런스 원리 | 화면 | 파일 | 점수 | 검수 |
|---|---|---|---|---|---|---|
| 0 | 밝은 화면 회색 글자 대비 3.4:1 (axe 위반 최대 54건/화면) | WCAG 2.2 AA | 전체 | `style.css` 2탄 블록: `--label2` .6→.78 | 접근성 | axe 위반 0 |
| 0 | 어두운 화면 고른 날짜 탭 흰 글자 대비 2.3:1 | WCAG | 일정 | `style.css`: `#fff`→`var(--on-accent)` 4곳 | 접근성 | axe 위반 0 |
| 0 | 옅은 바탕 위 강조색 글자 4.1~4.46:1 (D-day, 의견 버튼, 활동 태그, 비 예보 파랑) | WCAG | 홈·일정·장소 | `style.css`: 밝은 화면만 20% 짙게, `--blue-ink` 토큰 | 접근성 | axe 위반 0 |

움직임 값: 누름 .12s, 시트 닫힘 .2s(휴대폰 .26s), 탭 표시 .38s, 화면 등장 .32s. 모두 `transform/opacity`. `prefers-reduced-motion`이면 전부 끔.

보존한 것: 4탭 구조, 테마 6종, 장소·시간표 팝업 129개, `#day3` 같은 주소, `#sync=` 링크, 첫 방문 안내, 환율 방향 버튼, 오프라인 sw.js. 데이터 구조(trip.json) 변경 없음.
