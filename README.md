# 여행 플래너

여행 동선, 지도, 예약, 비용을 일행과 함께 보는 사이트예요.
주소: https://daily-jh.github.io/travel-planner/

## 구조

- `trips/<연도-월-도시>/trip.json`: 여행 하나의 데이터 (날짜별 동선, 시간표, 장소 카드, 후보, 비용, 출발 전 확인)
- `planner/build.py`: `trip.json`을 읽어 `_site/`에 페이지와 캘린더 파일(`calendar.ics`)을 만드는 생성기 (파이썬 표준 라이브러리만 사용)
- `planner/style.css`, `planner/app.js`: 공통 디자인과 지도 전환 스크립트
- `.github/workflows/pages.yml`: `main`에 올리면 자동으로 빌드해서 GitHub Pages에 배포

## 새 여행 추가

Claude에게 여행 메모(날짜·인원·숙소·항공·가고 싶은 곳)를 주고 "새 여행 추가"라고 하면 아래 순서로 만들어요. 직접 할 때도 같아요.

1. 뼈대 만들기: `python planner/new_trip.py --slug 2027-10-osaka --title "오사카, *가을* 먹방" --short 오사카 --start 2027-10-02 --end 2027-10-05 --city 오사카 --theme temple`
   날짜별 칸, 6칸 간단 일정, 비용표 날짜 줄까지 만들어지고 채울 곳은 `{채우기}`로 표시돼요.
2. 채우기: 항목 설명은 [`planner/TRIP_FORMAT.md`](planner/TRIP_FORMAT.md). 확정되지 않은 정보는 `{확인 필요}`라고 쓰면 배지로 표시돼요.
3. 점검: `python planner/check_trip.py trips/<폴더>` — 날짜·6칸 구조·휴무 요일·남은 빈칸·개인정보(전화번호·예약번호·이메일)를 확인해요. 배포 때도 자동으로 돌고, 실패하면 배포되지 않아요.
4. 썸네일: `node planner/tools/render-assets.js <폴더>`로 `og.png`를 만들어요.
5. `main`에 올리면 1~2분 뒤 여행 목록과 캘린더 파일이 함께 반영돼요.

테마: `hakata`(남색·매화), `ocean`(바다·섬), `forest`(숲·온천), `snow`(겨울·설경), `citrus`(열대·휴양), `temple`(고도·사찰).
일본이 아닌 곳은 `lang`(회화 언어·택시 카드 문장)과 `timezone`을 바꿔요. 아는 도시는 `new_trip.py`가 자동으로 넣어요.

국내 여행도 돼요. `--city 강릉`처럼 국내 도시를 주면 `country`가 `한국`이 되고, 장소 링크는 **네이버 지도**(휴대폰은 네이버 지도 앱)로 열려요. 환율·면세·회화·택시 카드·현지 시각처럼 해외에서만 쓰는 도구는 숨겨요. 자세한 건 [`planner/TRIP_FORMAT.md`](planner/TRIP_FORMAT.md)의 '국내 여행'.

로컬에서 보기: `python planner/build.py` 후 `_site/index.html`을 열어요.

## 공용 비밀번호

배포할 때 모든 페이지를 비밀번호로 암호화해요(`planner/lock.py`). 주소를 알아도 비밀번호 없이는 내용을 볼 수 없어요.

- 비밀번호 정하기·바꾸기: 저장소 Settings → Secrets and variables → Actions → `SITE_PASSWORD`. 바꾼 뒤 Actions에서 'Deploy site'를 다시 돌리면 반영돼요. 비어 있으면 새 배포가 중단돼요. 로컬 빌드는 계속 사용할 수 있어요.
- 한 번 넣으면 그 기기에서 기억해요. 주소 뒤에 `?lock`을 붙이면 그 기기에서 잊어요.
- 캘린더(`.ics`)·구글 시트(`schedule.csv`)·엑셀·PDF는 앱이 직접 읽어야 해서 암호화하지 못해요. 대신 비밀번호로 만든 긴 폴더(`trips/<폴더>/d-…/`) 아래로 옮겨서, 잠긴 페이지 안에서만 주소를 알 수 있어요. 비밀번호를 바꾸면 이 주소도 바뀌니 캘린더 구독을 다시 해야 해요.

공개 저장소의 원본과 커밋 이력은 페이지 잠금과 별개로 공개돼요. 비공개 일정, 예약번호와 바우처 원본은 저장소에 올리지 마세요. 일정 파일 주소를 받은 사람도 직접 열 수 있으니 전달 범위를 확인하세요.

## 캘린더

각 여행 페이지의 '캘린더에 추가' 버튼이 `calendar.ics`를 열어요.
아이폰 캘린더 구독: 설정 → 캘린더 → 계정 → 계정 추가 → 기타 → 구독 캘린더 추가에
여행 페이지 '캘린더에 추가' 버튼의 주소(비밀번호를 걸었다면 `trips/<폴더>/d-…/calendar.ics`)를 넣으면 일정이 바뀔 때 자동으로 반영돼요.

## 우리의 픽 저장

`planner/site.json`의 `supabase_url`, `supabase_anon_key`가 비어 있으면 픽은 각자 휴대폰에만 저장돼요.
둘을 채우면 모두가 같은 픽을 보고 고칠 수 있어요. Supabase SQL 편집기에서 한 번 실행:

```sql
create table picks (
  trip text not null, place text not null, person text not null,
  created_at timestamptz default now(),
  primary key (trip, place, person)
);
alter table picks enable row level security;
create policy "read" on picks for select using (true);
create policy "add" on picks for insert with check (true);
create policy "remove" on picks for delete using (true);
```

## 여행 도구 (여행 페이지 안)

도구는 쓰는 때에 따라 **떠나기 전 · 현지에서 · 함께·기록** 세 묶음으로 나뉘고, 출발 전·여행 중·다녀온 뒤에 맞춰 지금 쓸 묶음이 맨 앞에 와요(묶음은 `planner/build.py`의 `TOOL_GROUPS`). 한국과 시차가 없으면 현지 시각 도구는 숨겨요. 출발 전 확인·내려받기는 준비 탭에만 있어요.

- **찾기**: 맨 위 돋보기. 장소·시간표·후보·플랜 B·도구·준비 항목을 한 번에 찾고, 누르면 그 팝업이나 화면으로 바로 가요.
- **운항 상태**: 지금 카드의 항공편 줄에서 Flightradar24로 지연·게이트를 확인해요 (`flights[].no`).
- **날씨**: `trip.json`의 `geo`(위도·경도)로 Open-Meteo에서 불러와요. 출발 16일 전부터는 예보, 그 전에는 작년 같은 날짜의 실제 날씨예요.
- **환율 계산**: `currency.code`로 실시간 환율(open.er-api.com)을 불러오고, 안 되면 `fallback_krw_per_100`을 써요.
- **현지 한마디**: `phrases`의 [한국어, 현지어, 발음]. 누르면 휴대폰이 현지어로 읽어 줘요.
- **함께 쓴 돈**: 누가 얼마 냈는지 적으면 정산 금액을 계산해요. 목록에서 항목을 누르면 고칠 수 있고, 일행과 합칠 때는 나중에 고친 쪽이 남아요. 지금은 각 휴대폰에만 저장돼요.
- **공금**: 공금을 커플통장·트래블카드(원)와 현금(현지 돈) 두 지갑으로 나눠 넣은 돈을 적으면, 함께 쓴 돈에서 '공금 카드'·'공금 현금'으로 적은 지출만큼 빠져 남은 돈이 보여요. 카드 지출은 현지 돈으로 적어도 환율로 바꿔 빼요. 아래 탭 '예산' 맨 위와 함께 쓴 돈 팝업에 같은 카드가 있고, 총 필요 예산과도 비교해요. 공금 지출은 개인 정산에서 빠져요. 넣은 돈은 `tp-pool-<폴더>`에 이 휴대폰에만 저장돼요.
- **예약 오픈·마감 알림**: `trip.json`의 `deadlines`. 출발 전 확인의 같은 예약 항목과 한 몸이라, 어느 쪽에서 체크해도 둘 다 바뀌고 체크 항목 옆에 남은 날이 보여요. 첫 화면 '다가오는 예약'과 여행 홈에 남은 시간(하루 안이면 시·분, 한 시간 안이면 초)이 보여요. 캘린더 구독에도 하루 전·15분 전 알림으로 들어가고, 카드마다 '캘린더 알림'으로 하나만 받을 수도 있어요. '했어요'는 각 휴대폰에 저장되고 '일행과 공유' 링크로 합쳐져요.
- **준비물 체크**: '출발 전 확인' 항목을 누르면 체크가 저장돼요.
- **여행 중 모드**: 여행 날짜가 되면 맨 위에 '지금·다음 일정' 카드가 떠요. 미리 보려면 주소 뒤에 `?now=2027-02-27T13:30`.
- **오프라인**: 한 번 열어 본 페이지는 인터넷이 없어도 열려요.
- **일본어 회화**: `phrases`를 `[{"cat": "식당", "items": [[한국어, 일본어, 발음], ...]}]`처럼 분류별로 써요. ⤢를 누르면 점원에게 보여 줄 수 있게 크게 떠요.
- **캐리어 짐**: `packing`에 분류별 `[물건, "기내" 또는 "위탁"]`. 체크·직접 추가한 물건은 각 휴대폰에 저장돼요.
- **비상 연락**: `emergency`의 [이름, 번호]. 번호를 누르면 전화가 걸려요.

## 화면 구성 (여행 페이지)

아래 탭 4개로 나뉘어요. 홈(지금 일정 카드, 여행 도구, 한눈에 보는 일정), 일정(날짜별 동선·지도·시간표), 장소(우리의 픽, 장소 찾기, 후보), 준비(숙소·이동·예약, 비용, 출발 전 확인).
주소 뒤에 `#day3`, `#before`처럼 붙이면 그 화면으로 바로 열려요.

## 서버 없이 되는 기능

- **일행과 공유**: 맨 위 '일행과 공유'에서 일정 링크만 보내거나, 내 픽·함께 쓴 돈·출발 전 체크를 링크의 `#sync=` 뒤에 담아 보내요. 받은 사람이 열어 합치기를 누르면 그 휴대폰 기록과 합쳐져요. 서버에는 아무것도 올라가지 않아요.
- **사진 일지**: 시간표 줄의 '사진 추가'로 넣은 사진은 긴 쪽 1280px로 줄여 휴대폰 안(IndexedDB)에만 저장해요. 링크로는 전달되지 않아요.
- **면세 목록**: 함께 쓴 돈에서 '면세로 샀어요'를 켜고 추가하면 면세 구매만 따로 모아 보여요.
- **플랜 B**: 날짜의 `alternatives`가 팝업으로 열려요. 출발 16일 전부터 비 올 확률이 50% 이상인 날은 날씨와 지금 카드에 '플랜 B'가 떠요. 미리 보기: `?now=2027-03-01T19:30&rain=70`.
- **오프라인**: 사이트를 한 번 열면 모든 여행 페이지를 미리 저장해요.

## 내려받기·연동 (준비 탭 맨 아래)

- **엑셀 일정표** `itinerary.xlsx`: 요약·일정·장소·후보·예상 비용·정산·준비물·출발 전 확인 시트. 정산 시트에 쓴 돈을 적으면 1인당·정산 금액이 계산돼요. `planner/export.py`가 만들어요(openpyxl).
- **PDF 여행 책자** `booklet.pdf`: A5 크기, 날짜별 일정과 구글 지도 경로 QR, 회화, 택시 카드. `booklet.html`을 `planner/tools/render-pdf.js`가 PDF로 저장해요. 책자 화면에서 바로 인쇄해도 돼요.
- **구글 캘린더 구독**: `calendar.ics`를 구글 캘린더에 구독으로 넣어요.
- **구글 시트**: 새 시트 A1에 `=IMPORTDATA("…/schedule.csv")`를 넣으면 일정이 들어오고 사이트가 바뀌면 따라 바뀌어요.
- **내 지출 CSV**: 함께 쓴 돈 기록을 CSV로 내려받아요.

엑셀·PDF는 GitHub Actions에서 만들어요. 실패해도 사이트 배포는 계속돼요.

## 여행 리포트·네컷 사진·쇼핑 리스트

- **여행 리포트**: 이 휴대폰의 함께 쓴 돈, 픽, 여행 기록으로 날짜별 지출(예상 범위와 비교), 분류별·낸 사람별 지출, 픽 나눔, 다녀온 곳을 차트로 보여 줘요.
- **네컷 사진**: 사진관 스티커 사진처럼 사진 네 장을 세로 네컷 또는 2×2 프레임에 담아요. 프레임은 여행지(그 여행 손그림 `landmark`를 크게, 검정 펜선), 테마(표지 그라데이션), 파스텔(테마 옅은 색), 흰색, 검정 다섯 가지예요. 여행지 외에는 사이트처럼 시스템 글꼴·둥근 모서리·테마 색만 써요. 칸은 비워 둔 채 시작해요. 인생네컷처럼 칸을 고르고 아래 사진 목록(여행 기록 사진 + '사진 추가')에서 눌러 넣고, 사진을 끌어 위치를, 두 손가락이나 −/+로 크기를 맞추고, ↑↓로 칸 순서를 바꿔요. 새 여행도 `theme`과 `landmark.art`만 있으면 저절로 맞춰져요. 사진은 휴대폰 밖으로 나가지 않아요.
- **쇼핑 리스트**: `trips/<폴더>/shopping.json`이 있으면 `trips/<폴더>/shopping/` 페이지가 생겨요. 상품마다 `cat, ko, ja, brand, size, price_yen, price_note, where, why, look, url, shape, colors`. 그림은 `shape`(box·bag·bottle·can·tube·jar·pack·stick·cup·onigiri·sheet·tin)와 `colors` 3개로 단순하게 그려요. 추천은 `stars`(1~5, AI 추천 별점)와 `pick`(한 줄 이유), 값을 못 확인한 참고가는 `approx: true`(화면에 "약 ¥"). 맨 위 `stars_note`는 별점 기준 설명이에요.

## 여행지 안내: 면세 환급·에티켓·역사·문화

- **면세 환급** (현지에서): 2026-11-01부터 바뀐 일본 면세(세금 포함 결제 → 출국 때 세관 확인 → 환급)에 맞춘 계산기. 영수증을 담으면 가게·날짜별로 세금 빼고 ¥5,000을 넘었는지, 돌려받을 돈(수수료 빼고)과 원화, 한국 1인 면세 한도 $800 대비를 보여 줘요. '함께 쓴 돈'에서 '면세로 샀어요' 기록을 불러올 수 있고, 처리 순서(떠나기 전~한국 도착 15단계)를 체크해 가며 볼 수 있어요. 제도 자료는 `planner/countries/jp.json`의 `taxfree`.
- **에티켓·주의** (떠나기 전): 나라 공통 + 도시 에티켓을 꼭 지켜요·조심해요·알아 두면 좋아요로 걸러 보고, 일정에 나오는 곳은 날짜 버튼으로 그 시간표 줄을 열어요.
- **역사·문화** (떠나기 전): 랜드마크 그림, 날짜별로 만나는 이야기, 역사 타임라인, 문화·맛 카드. 시간표 줄 팝업에도 '알아 두기'와 '이곳의 이야기'가 붙어요.
- 자료 형식은 `planner/TRIP_FORMAT.md` '여행지 안내'. 새 여행은 `trips/<폴더>/guide.json`만 쓰면 돼요.

## 둘이 함께: 함께 고르기·돌아보기

- **함께 고르기** (함께·기록): 시간표에 '택1'로 남긴 곳(예: `저녁 택1 · 하야토 / 바쿠로`)을 각자 골라요. 같으면 바로 정해지고, 갈리면 지금까지 덜 정한 사람 차례로 정하거나 운에 맡겨요. 정한 곳은 시간표(→ 이름)·지금 카드·다음 장소 길찾기에 반영돼요. 줄 팝업 안에서도 고를 수 있어요.
- **돌아보기** (함께·기록): 날마다 저녁 질문 하나(여행 중 저녁 7시부터 지금 카드에 떠요)에 둘이 한 줄씩 답하고, 다녀온 곳·별점·사진과 함께 날마다 한 장으로 모아 봐요. 여행 끝날 무렵 '1년 뒤 오늘' 캘린더 알림(.ics)을 받을 수 있어요.
- 둘 다 이 휴대폰에만 저장되고 '일행과 공유' 링크로 서로 합쳐져요. 코드는 `planner/together.py`, `planner/together.js`.

## 디자인 시스템

테마 색은 `planner/themes.json` 한 곳에만 있고, 규칙은 `planner/DESIGN.md`, 모습은 사이트의 `/design/` 페이지에서 봐요.

## 기기 기록 백업

여행 페이지의 ‘일행과 공유’에서 이 기기의 캐리어 짐·건너뛴 일정·대체 장소·지출·공금·픽·체크·예약 완료 상태·함께 고르기·돌아보기 답변·좌석을 JSON으로 내려받을 수 있어요. 복원하면 파일에 들어 있는 항목을 해당 여행의 기기 기록에 덮어써요. 복원 전 현재 기록을 먼저 내려받을 수 있어요. 바우처는 QR·바우처 도구에서 별도로 내보내세요. 여행 사진과 이 목록 밖의 도구 기록은 이 백업에 들어가지 않아요.

기본 공유 링크와 백업 파일은 받은 사람이 열 수 있어요. ‘비밀번호 걸어 보내기’를 고르면 기록을 암호화하고, 받은 사람은 링크를 열 때 비밀번호를 입력해요. 비밀번호는 링크와 별도로 전달하세요.
