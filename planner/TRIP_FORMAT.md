# trip.json 형식

여행 하나 = `trips/<연도-월-도시>/trip.json` (+ `og.png` 링크 썸네일).
`planner/build.py`가 이 파일로 여행 페이지, `calendar.ics`, 첫 화면 여행 목록 카드를 만든다. 목록 등록은 따로 할 일이 없다.
가장 완성된 예시는 `trips/2027-03-fukuoka/trip.json`.

뼈대 만들기 → 채우기 → 점검:

```
python planner/new_trip.py --slug 2027-10-osaka --title "오사카, *가을* 먹방" --short 오사카 \
    --start 2027-10-02 --end 2027-10-05 --city 오사카 --theme temple --travelers 지훈,지윤
python planner/check_trip.py trips/2027-10-osaka
python planner/build.py && node planner/tools/render-assets.js 2027-10-osaka
```

## 글자 규칙 (모든 문자열)

- `**굵게**` → 굵은 글씨
- `{확인 필요}` → 노란 배지. 영업시간·요금·집합 시간처럼 아직 확정 못 한 정보에 붙인다. 추측으로 채우지 않는다
- `{채우기}` → `new_trip.py`가 남긴 빈칸. 남아 있으면 `check_trip.py`가 실패한다
- 제목의 `*별표*` → 강조색
- 전화번호·예약번호·이메일·여권번호는 어디에도 쓰지 않는다 (공개 저장소). 예약은 "핫페퍼 예약 (19:00)"처럼 경로와 시각만

## 위쪽 항목

| 키 | 형식 | 설명 |
|---|---|---|
| `title` / `short` / `eyebrow` | 문자열 | 표지 제목, 짧은 이름, 위 작은 글씨(`FUK · 博多`) |
| `theme` | `hakata` `ocean` `forest` `snow` `citrus` `temple` | 남색·매화 / 바다·섬 / 숲·온천 / 겨울·설경 / 열대·휴양 / 고도·사찰 |
| `landmark` | `{"name","art"}` | 첫 화면 여행 카드의 랜드마크 그림. 아래 '랜드마크 그림' 참고 |
| `travelers` | `[{"name","tone":"pri"|"acc"}]` | 픽(♥)을 고를 사람. 이름만 |
| `default_picks` (선택) | `{"version","note","picks":{"이름":[장소 이름]}}` | 일정을 짠 사람의 픽을 처음 열 때 한 번 채워 둔다. 장소 이름은 `places.name`·`candidates.name`과 같게. 목록을 바꾸면 `version`도 바꿔야 다시 채워진다 (지운 픽은 되살리지 않음) |
| `start` `end` | `YYYY-MM-DD` | 첫날·마지막 날 |
| `timezone` `country` | `Asia/Tokyo`, `일본` | 캘린더 시간대, 목록 카드. `country`가 `한국`이면 국내 여행(아래 '국내 여행') |
| `domestic` | `true`/`false` (선택) | 국내 여행인지. 없으면 `country`로 정한다 |
| `map` | `"naver"`/`"google"` (선택) | 장소 링크·캘린더 위치를 여는 지도. 없으면 국내는 네이버, 해외는 구글 |
| `intro` | 문자열 | 한두 문장 소개 |
| `facts` | `[[이름, 값]]` | 표지 아래 칩 (숙소·항공·환율) |
| `links` | `[{"label", "url"|"query", "primary"}]` | 표지 버튼. `query`는 지도 검색어 (해외 구글, 국내 네이버) |
| `stay` `transport` | `[[이름, 값]]` | 준비 탭 숙소·이동 |
| `stay_query` / `stay_ja` | 문자열 | 숙소 지도 검색어 / 택시 카드용 현지어 숙소명 (국내는 `stay_ja` 없음) |
| `pace` | `{"columns":[날짜,권역,강도,숙소 복귀], "rows":[[...]]}` | 날짜별 권역과 강도(상·중·하) |
| `reservations` | `{"required":[[언제, 무엇]], "recommended":[...]}` | 필수 예약 / 권장 예약 |
| `deadlines` | `[{"at":"2026-11-24 20:00","kind":"open"|"due","what","note","url","tz"}]` | 예약 오픈·마감 알림. 첫 화면 '다가오는 예약'과 여행 홈 카드에 남은 시간이 보이고, 캘린더에 하루 전·15분 전 알림으로 들어간다. `at`이 날짜만이면 하루 종일 일정(전날·당일 오전 9시 알림). `tz`를 안 쓰면 한국 시각. 날짜가 확실한 것만 넣는다 |
| `closures` | `[[장소, 휴무, "M/D 요일", "ok"|"check"]]` | 방문 요일 휴무 점검 |
| `candidates` | `[{"group","name","rating","category","memo","status","reason","query"}]` | 후보·배제 목록. `status`: `sel` 선정, `alt` 대안, `off` 미배치, `exc` 배제. `rating`은 `"4.2(2,873)"`처럼 쓰면 AI 추천이 계산된다 |
| `budget` | `{"title","unit","note","rows":[[날짜, 내역, 최소, 최대, 원화]],"total":[...],"footnote"}` | 1인 비용. 날짜 줄 수 = 일수 |
| (비용 구성) | 자동 | 준비 탭 비용 카드의 종류별 막대(식비·카페·간식·체험·입장료·음료·추가 주문·여유분)는 그날 `blocks`의 `type`과 `what`의 가격(¥1,080, ₩12,000, 1.2만 원, `A / B`는 택1, `(+C)`는 선택)에서 `planner/costs.py`가 계산해요. 메뉴 합이 계획 범위보다 크면 범위를 올리고, 남는 몫은 '음료·추가 주문'이 돼요. 종류를 바꾸려면 블록에 `"cost_cat": "간식"`(빼려면 `""`), 직접 적으려면 비용 줄 6번째 칸에 `[{"cat","place","lo","hi"}]` |
| `before` | `{"note","lists":[[제목, [항목]]]}` | 출발 전 확인 (예약 / 전화·사이트 확인 / 꼭 챙길 것) |
| `calendar_extra` | `[{"date","start","end","title","location","description","alarm"}]` | 시간표에 없는 캘린더 일정 (투어 집합 등) |
| `calendar_skip` | `{"YYYY-MM-DD": [구분]}` | 그날 캘린더에서 뺄 시간표 구분 (calendar_extra로 대신할 때) |
| `source` | 문자열 | 출처·기준일 (페이지 맨 아래) |
| `geo` | `{"lat","lon","city"}` | 날씨 |
| `currency` | `{"code","symbol","name","fallback_krw_per_100"}` | 환율 계산. 국내 여행이면 빼도 된다 |
| `lang` | `{"code":"ja-JP","name":"일본어","icon":"あ","taxi":"{stay}までお願いします"}` | 회화 이름·음성 언어·택시 카드 문장. 없으면 일본어 |
| `local_tz_note` | 문자열 | "한국과 시차 없음" 등 |
| `phrases` | `[{"cat", "items":[[한국어, 현지어, 발음]]}]` | 현지 회화 (분류 6개 안팎) |
| `packing` | `[{"cat", "items":[[물건, "기내"|"위탁"]]}]` | 캐리어 짐 |
| `packing_note` | 문자열 (선택) | 짐 팝업 부제. 없으면 "5월 초 강릉 날씨 기준"처럼 자동 |
| `emergency` | `[[이름, 번호]]` | 경찰·구급·영사콜센터 같은 공공 번호만 (국내: 112·119·1330) |
| `emergency_link` | URL | 총영사관 등 |
| `flights` | `[{"date","dep","from","to","no","airline","dep_tz"}]` | 지금 카드의 '공항 도착까지' 계산 |
| `areas` (선택) | `{"권역": [위도, 경도]}` | 주변 대안의 거리 계산용 동네 중심 좌표. `blocks.area`·`candidates.area`가 이 이름을 쓴다 |
| `vouchers` (선택) | `[{"id","label","hint","when"}]` | QR·바우처 칸 **이름만**. 번호·QR 사진은 여행자가 각자 휴대폰에 넣는다 (사이트·링크에 안 올라감). 예약번호를 여기에 쓰지 말 것 |
| `transit_pass` (선택) | `{"name","price","fare_note","touch","days":[{"date","rides":[[구간, 요금]]}]}` | 1일권 손익. 날마다 지하철 탈 구간과 편도 요금 |
| `leftover` (선택) | `{"title","tips":[[제목, 설명]],"airport":[[언제, 할 일]]}` | 귀국 날 동전 털기·공항 순서 |

후보(`candidates`)에 `area`(권역 이름)와 `open`(`"17:00-23:00"`, 밤을 넘기면 `"18:00-02:00"`)을 넣으면 `off`·`alt` 후보가 '주변 대안'에 나온다. 영업시간을 확인하지 못했으면 업종별 보통 시간으로 넣고, 화면에는 '어림'으로 표시된다.

## days[] (하루)

```json
{
 "date": "2027-02-27", "theme": "하카타·나카스", "color": "ume",
 "summary": "도착일 · 15시 체크인 · 22시 전후 숙소 복귀",
 "simple": [{"slot": "아침", "time": "~09:30", "text": "..."}, ... 6칸],
 "route": {"mode": "transit", "stops": [{"label": "구시다 신사", "query": "櫛田神社 福岡"}]},
 "blocks": [{"time": "13:00–14:00", "type": "점심", "place": "이치란 본사 총본점", "what": "라멘 ¥1,080", "move": "도보 5분", "note": "12~13시 피크, 15~20분 대기"}],
 "alternatives": [{"when": "비·강풍", "text": "..."}],
 "plan_b": {"title": "비 오는 토요일 · 하카타역 실내 동선", "when": "언제 이 일정으로 바꾸는지",
            "simple": [{"slot": "아침", "time": "08:00", "text": "..."}, ... 6칸],
            "places": [{"name", "local", "query", "hours", "why", "cost"}]},
 "places": [{"name", "local", "query", "address", "hours", "why", "tip", "cost"}]
}
```

- `simple`: 꼭 `아침 · 오전 · 점심 · 오후 · 저녁 · 밤` 6칸, 이 순서
- `color`: `ume` `hakata` `lantern` `tide` `sea` `gold` `plum` `indigo`. 날마다 다르게
- `route.mode`: `transit` `walking` `driving`. `stops`는 방문 순서, 10곳 이하. `query`는 현지어 이름 + 도시가 가장 정확하다 (국내는 "강릉 오죽헌"처럼 한국어 이름 + 지역)
- `route.stops[].lat` `lng` (선택, 국내): 위도·경도. 그날 모든 장소에 있으면 '네이버 지도 길찾기' 버튼이 앱 길찾기로 열린다 (차·도보는 경유지 5곳까지, 대중교통은 출발→도착). 네이버 지도에서 확인한 좌표만 넣고, 모르면 빼둔다
- `blocks.type`: `아침` `점심` `저녁` `밤` `카페` `이동` `숙소` `활동` `쇼핑`
- `blocks.time`에 `HH:MM`이 있어야 캘린더에 들어간다 (`10:10–11:35`). `오전`처럼 쓰면 페이지에만 보인다
- `blocks`의 `note`·`what`에 `예약`, `현금`/`카드 불가`, `줄서기`/`대기`가 있으면 배지가 자동으로 붙는다
- `blocks.area`(선택): 그 줄의 권역(`areas`의 이름). 브리핑 카드의 '주변 대안'이 이 동네 기준으로 열린다
- `blocks.alert`(선택): `{"by":"19:45","text":"접수 마감 20:00 · 30분~1시간 대기"}`. 시간표에 '⏰ 19:45 전' 배지, 여행 중 위쪽 카운트다운(60분 전부터)에 쓰인다. 확인 못 한 시각은 `text`에 `{확인 필요}`
- 시각은 모두 여행지 현지 시각(`timezone`). 인천 출발처럼 한국 시각은 현지 시각으로 바꿔 넣고 원래 시각은 `what`에 적는다
- 항공편 번호(`TW0203`, `7C2203`)가 `what`에 있으면 캘린더 알림이 3시간 전, 예약 배지가 있으면 1시간 전
- `plan_b`(선택): 하루 전체를 바꾸는 대안 일정. `simple`은 원래 일정처럼 6칸. 플랜 B 팝업과 PDF 책자에 나오고 캘린더에는 넣지 않는다. `places.hours`도 휴무 요일 점검을 받는다
- `places.hours`에 `화요일 휴무`, `월·화 휴무`, `토·일만`처럼 쓰면 `check_trip.py`가 그 요일 방문을 잡아낸다

## 국내 여행

`country`가 `한국`이면(또는 `"domestic": true`) 국내 여행으로 본다. `new_trip.py --city 강릉`처럼 아는 국내 도시는 자동으로 채운다.

- 지도: 장소·동선·숙소·후보 링크와 캘린더 위치가 **네이버 지도**로 열린다. 휴대폰에서는 네이버 지도 앱으로 열고, 앱이 없으면 웹(map.naver.com)으로 연다
- 페이지 안 지도는 키 없이 되는 구글 지도 그대로 (네이버 지도를 페이지 안에 넣으려면 네이버 클라우드 Maps API 키가 필요해서 아직 안 함)
- 숨기는 도구: 환율 계산·면세(함께 쓴 돈의 '면세로 샀어요')·현지 회화·택시 카드·현지 시각. `currency` `lang` `phrases` `stay_ja` `local_tz_note` `flights`는 넣지 않아도 된다
- 비용·정산은 원화(₩) 그대로. `budget.unit`은 `₩`
- `eyebrow`는 "강원 강릉 · KTX"처럼 지역과 교통

## 랜드마크 그림 (`landmark`)

첫 화면 여행 목록 카드 위쪽의 랜드마크 그림이에요. 없으면 `og.png` 썸네일로 보여요.
실제 사진은 쓰지 않아요. **기준 그림은 `trips/2027-03-fukuoka/landmark.webp`** (지훈이 고른 후쿠오카 강변 산책 그림)이에요. 새 여행지도 이 그림의 선·색감·느낌을 최대한 그대로 따라 그려요.

- 선: 가늘고 떨리는 검정 펜선. 끊기고 겹치고 덧그린 자국이 남아 있고, 건물은 특징 선만
- 색: 흰 바탕에 색연필·크레용으로 빗금 치듯 칠한 파스텔 색(분홍·하늘·살구·노랑·베이지). 칠이 선 밖으로 살짝 삐져나와도 좋고, 그라데이션·입체 그림자는 없음
- 구성: 앞쪽에 여행자 두 사람(지훈: 짧은 검은 머리·카메라, 지윤: 긴 검은 머리·커피 등, 계절 옷차림)이 걷거나 이야기하는 모습. 뒤로 그 도시 랜드마크 2~3개를 여행 콜라주처럼, 작은 행인 몇 명, 계절 꽃·나무. 넓은 흰 여백
- 글자는 손글씨 도시 이름 하나 정도만 (예: Fukuoka 밑줄). 날짜·로고 없음
- 파일: 이미지 생성으로 만든 그림은 가로 3:2 안팎, 1280px로 줄여 `trips/<폴더>/landmark.webp`(품질 82). 카드는 8:5로 위아래가 조금 잘려 보여요
- 위쪽 왼쪽·오른쪽 모서리는 D-day와 이름 칩이 올라가니 중요한 것(얼굴·랜드마크 꼭대기)을 두지 않아요
- 이미지 생성 도구가 없으면 완성 프롬프트를 먼저 만들어 지훈에게 주고, 받은 그림을 넣어요

```json
"landmark": {"name": "후쿠오카 타워", "art": "landmark.webp"}
```
