# 여행 플래너 디자인 시스템

여행이 늘어도 화면이 같은 규칙으로 보이게 하려는 기준이에요. 실제 모습은 사이트의 `/design/` 페이지에서 볼 수 있어요.

## 원칙

1. **애플풍으로 깔끔하게.** 시스템 글꼴(SF·Apple SD Gothic Neo, 그 밖의 기기는 Pretendard), 흰 카드와 회색 바탕, 큰 둥근 모서리.
2. **장식은 쓰지 않아요.** 바코드 같은 줄무늬, 손글씨, 고정폭 글꼴, 과한 그림자는 넣지 않아요.
3. **휴대폰이 먼저.** 390px 폭에서 가로 스크롤이 생기면 안 돼요. 표는 휴대폰에서 목록으로 바꿔요.
4. **색은 한 곳에서.** 여행 테마 색은 `planner/themes.json`에만 있어요. CSS에 테마 색을 직접 쓰지 않아요.
5. **개인정보는 넣지 않아요.** 전화번호·예약번호는 화면, 파일, 저장소 어디에도 쓰지 않아요.

## 토큰

### 테마 색 (`planner/themes.json`)

여행마다 `trip.json`의 `"theme"`으로 하나를 골라요. 각 테마는 밝은 화면(`light`)과 어두운 화면(`dark`) 값을 따로 가져요.
키가 테마 이름이고 값은 `label, mood, light, dark`예요. `build.py`가 이 파일로 `.theme-<이름>` CSS를 만들어 `assets/style.css` 앞에 붙여요.

| 토큰 | 쓰임 |
|---|---|
| `--pri` | 표지 그라데이션, 주 버튼, 강조 숫자 |
| `--pri-soft` | 주 색의 옅은 배경 (경로 상자, 선택된 칩) |
| `--acc` | 포인트 (표지의 빛, 예약 필수 배지) |
| `--acc-soft` | 포인트의 옅은 배경 |
| `--paper`, `--surface2`, `--line` | 바탕·채움·선 (애플 기본값 `--bg`·`--fill`·`--sep`이 덮어씀) |

| 테마 | 분위기 | 밝은 pri / acc | 어두운 pri / acc |
|---|---|---|---|
| hakata | 도시·야경 | #24346b / #c13d69 | #9fb3ec / #f08eb0 |
| ocean | 바다·섬 | #0d5a6b / #d9583e | #7fd0dc / #ff9a83 |
| forest | 숲·온천 | #2c5536 / #b06a14 | #9fd1a8 / #e8b665 |
| snow | 겨울·설경 | #2b4862 / #3f86c9 | #a9c6e3 / #8fc3f5 |
| citrus | 열대·휴양 | #1d5c48 / #d9741f | #86d3b5 / #ffb36b |
| temple | 고도·사찰 | #3d2a22 / #c0392b | #e2c9b8 / #f08a7c |

새 테마를 만들 때는 `themes.json`에 같은 키 7개(`paper, surface2, line, pri, pri-soft, acc, acc-soft`)를 밝은·어두운 값으로 넣어요. 글자와 `--pri` 대비는 4.5:1 이상이어야 해요.

### 글자 크기

| 토큰 | px | 쓰임 |
|---|---|---|
| `--fs-large` | 34 | 큰 제목 |
| `--fs-t1` | 28 | 제목 1 |
| `--fs-t2` | 22 | 제목 2, 숫자 타일 |
| `--fs-t3` | 20 | 제목 3, 가격 |
| `--fs-body` | 17 | 본문, 카드 제목 |
| `--fs-sub` | 15 | 보조 본문, 설명 |
| `--fs-foot` | 13 | 각주, 메타 |
| `--fs-cap` | 12 | 캡션, 라벨 (이보다 작게 쓰지 않음) |

### 간격·모서리·그림자·움직임

- 간격: `--sp-1` 4 · `--sp-2` 8 · `--sp-3` 12 · `--sp-4` 16 · `--sp-5` 24 · `--sp-6` 32
- 모서리: `--r-xs` 6 · `--r-sm` 10 · `--r-ctl` 12(버튼·입력) · `--r-md` 14 · `--r-card` 20 · `--r-pill` 999
- 그림자: `--elev-1` 카드 한 단계만 써요.
- 움직임: `--dur-1` .18s(누름) · `--dur-2` .32s(시트) · `--dur-3` .5s(등장) · `--ease` iOS 스프링. `prefers-reduced-motion`이면 등장 효과를 꺼요.

#### 팝업·탭 움직임 (2탄)

- 팝업 시트는 열릴 때 기록을 한 칸 쌓아요. 휴대폰 뒤로 가기·Esc·✕·바깥 누르기가 모두 같은 닫힘 움직임(`data-phase="closing"`)을 거쳐요. 새 팝업도 `dialog.sheet`로 만들면 저절로 따라와요.
- 휴대폰에서는 시트 윗부분(또는 맨 위까지 올린 본문)을 끌어내리면 닫혀요. 끌기를 막아야 하는 요소엔 `data-noswipe`.
- 아래 탭은 `.tb-ind`가 미끄러지고, 탭마다 보던 위치를 기억해요. 같은 탭을 다시 누르면 맨 위로.
- 일정 탭은 옆으로 밀어 날짜를 넘겨요. 가로로 스크롤되는 요소와 지도 위에서는 넘기지 않아요.

### 글자 대비 (2탄)

- 보조 글자 `--label2`는 밝은 화면에서 `rgba(60,60,67,.78)` (흰 바탕 4.9:1). 애플 기본값 .6은 AA 미달이라 쓰지 않아요.
- 옅은 바탕 위 강조색 글자는 밝은 화면에서 `color-mix(… 80%, #000)`로 짙게, 어두운 화면은 원래 색.
- 파란 글자는 `--blue-ink`(밝은 #0063c4 · 어두운 #409cff). `#0a84ff`는 아이콘 배경에만.
- 강조색 바탕 위 글자는 `#fff` 대신 `var(--on-accent)`.

## 차트 색

`--viz-1`~`--viz-6`은 dataviz 기본 팔레트 순서(파랑, 주황, 청록, 노랑, 분홍, 초록)예요. 순서대로만 쓰고, 한 가지 값을 보여 줄 때는 `--viz-1` 하나만 써요. 어두운 화면 값은 따로 정해져 있어요. 막대 끝은 4px 둥글게, 칸 사이는 2px 띄우고, 값은 글자색(`--ink`·`--label2`)으로 써요.

## 컴포넌트

| 컴포넌트 | 클래스 | 쓰는 곳 | 상태 |
|---|---|---|---|
| 버튼 | `.btn`, `.btn.primary` | 팝업 아래 동작 | 기본, 누름(scale .96) |
| 세그먼트 | `.seg > button[aria-pressed]` | 분류·방향·크기 고르기 | 선택, 기본 |
| 여행 도구 타일 | `.tool.t-<이름>` + `.ti` 아이콘 | 홈 탭 | 누름 |
| 팝업 시트 | `B.sheet(id, 제목, 부제, 내용)` → `dialog.sheet` | 모든 상세 | 열림·닫힘(✕, 바깥, Esc) |
| 칩 | `.gchip`, `.pchip` | 숙소·예약·장소 | `hot`(예약 필수) |
| 내려받기 줄 | `.dl` + `.dl-ic.<종류>` | 준비 탭 '내려받기·연동' | 누름 |
| 숫자 타일 | `.rep-tile` | 여행 리포트 | 비어 있음(0) |
| 차트 | `.viz` (SVG + `.tip`) | 여행 리포트 | 마우스·손가락을 올리면 금액 |
| 상품 카드 | `.shop` | 쇼핑 리스트 | 담음(`aria-pressed`) |
| 배지 | `.chk`(확인 필요), `.ai`(AI 추천), `.fl`(예약·현금·줄서기) | 일정·장소 | — |

새 타일 아이콘 색은 `.t-<이름> .ti{background:linear-gradient(160deg,밝은색,짙은색)}` 한 줄로 정해요.
